# Harper Agent Skills

This repository contains "skills" that guide AI agents in developing Harper applications.

## Available Skills

- [Harper Architecture](harper-architecture/SKILL.md): Read before planning a Harper backend. Maps common services (Postgres, Redis, Express, Socket.io, S3, Pinecone, auth libraries) to the Harper feature that replaces them, so the app ships as one component.
- [Harper Best Practices](harper-best-practices/SKILL.md): Comprehensive guidelines for building, extending, and deploying Harper applications.
- [Harper Local Development](harper-local-dev/SKILL.md): Running Harper on a developer machine — parallel dev instances across git worktrees, with isolated loopback addresses and data roots.
- [Harper MCP](harper-mcp/SKILL.md): Comprehensive guide to Harper's Model Context Protocol (MCP) interface — server setup, tools, prompts, resources, rate limiting, quotas, and security.
